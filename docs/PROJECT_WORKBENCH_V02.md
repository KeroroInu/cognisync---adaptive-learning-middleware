# CogniSync v0.2：项目解构任务工作区

## 本版本目标

v0.2 开始把现有的“代码练习页面”逐步改造成单页项目解构工作台。学生不需要在多个页面之间来回跳转；完整项目演示、后续解构画布、代码区、过程记录和 AI 助手都将在同一工作区中以面板或浮动工具的方式协同。

当前版本先完成第一个可验证组件：可运行的贪吃蛇完整项目演示窗口。

## 已实现

- 在学生端“项目工坊”中接入 `SnakeProjectDemo`。
- 演示窗口默认打开，不发生页面跳转。
- 支持拖动标题栏改变窗口位置。
- 支持收起、展开和关闭；关闭后通过右下角入口重新打开。
- 贪吃蛇为真实可运行状态，不是循环装饰动画。
- 支持方向键、WASD 和屏幕方向键。
- 支持开始、暂停、重置、计分、食物增长、边界碰撞和自身碰撞。
- 碰撞后显示与项目解构相关的观察提示。
- 桌面端使用“米白纸面 + 深色实验屏幕 + Signal Lime”视觉体系。
- `720px` 以下自动转为单列，`480px` 以下进一步收紧标题和控制区。
- 组件自身不请求后端，不增加服务器并发压力；游戏循环只在窗口打开、展开且运行时存在。

## 代码入口

- 组件：`frontend/components/SnakeProjectDemo.tsx`
- 样式：`frontend/components/SnakeProjectDemo.css`
- 项目工坊接入：`frontend/views/Research.tsx`

## 已验证

- TypeScript 类型检查通过。
- 学生端生产构建通过。
- 桌面尺寸下完成开始、键盘转向、收起、展开、关闭和重新打开测试。
- `390 × 844` 窄屏下棋盘、方向键和底部操作按钮均可见，无横向溢出。
- 浏览器控制台未发现新增错误。

## 当前边界

- 贪吃蛇目前是项目工坊中的固定演示，尚未由教师端任务配置决定。后续需要在研究任务中增加 `project_demo_type` 或项目演示配置。
- 当前演示没有把“学生记录此刻”写入过程证据。后续观察阶段应允许学生对关键游戏状态添加观察标签。
- 现有 AI 助手仍为项目工坊右侧固定栏，下一步改造成可收起、可拖动的浮动助手，并与演示窗口共享浮动工具层。
- 当前项目任务仍只保存覆盖式代码与最终提交，尚未建立统一任务阶段、阶段产物和过程快照。

## 下一步开发顺序

1. 建立统一任务阶段：观察、结构解构、路径规划、分模块建构、整合解释。
2. 将项目工坊改为一个稳定的单页工作台，阶段切换只替换主工作区内容。
3. 为完整项目演示增加“记录此刻”，保存观察事件、标签和少量补充说明。
4. 实现低打字负担的观察画布：点击、标签、句式模板、拖拽和连线为主。
5. 将 AI 助手改为可拖动、可收起的浮动窗口；AI只做追问、检查和提示，不直接替学生生成完整解构。
6. 接入阶段产物、代码快照、运行报错、测试和修订记录。

## Git 提交原则

v0.2 后续按完整功能分开提交，不把无关历史修改混入同一次提交。建议提交顺序：

1. 完整项目演示窗口。
2. 统一任务阶段与后端数据模型。
3. 观察与问题表征工作区。
4. 功能结构解构画布。
5. 浮动 AI 助手与分级支架。
