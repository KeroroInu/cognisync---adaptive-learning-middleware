# 前后测管理与两组课堂入口（2026-09-09）

本文件记录实现与验证范围，不代表正式量表已经确定或教学效果已经验证。开发目录 `cognisync-classroom-acceptance`，分支 `codex/classroom-export-completion`；不修改旧 dev、论文或 Obsidian，不推送远端。

## 教师与学生如何使用

教师进入 `/admin/assessments`，分别新建前测、后测题本，编辑原题、单选/量表选项及其值、简答题、是否必答、题序、班级、来源与计分说明。保存为草稿不投放；开放需确认，可随时关闭。没有预置未经验证的正式量表，没有自动改写原题，也没有实现新量表自动计分。

同阶段、同班级范围只有一个开放版本；明确班级的安排优先于全校安排。前后测同时开放时先前测。首次开放后题本冻结，改题另存新版；同版本关闭重开不要求已完成学生重答，新版本则需要重新回答。建议正式收集前定稿，避免实验中改版。

注册只创建账号，不做旧画像初始化问卷。注册、登录后检查当前开放且未提交的问卷，有则先填写，没有则正常入课。课堂期间每分钟及窗口重新获得焦点时检查新安排，显示提醒，不直接卸载正在编辑的代码。该入口是课堂流程，不是考试防作弊锁屏。

学生页显示“我有几个问题想问你”，一次一道原题。原创 CSS 小表情营造对话感，不调用模型、不申请麦克风权限，支持减少动画。参考了 [Grok 动画复刻项目](https://github.com/ngocdevv/grok-bot-emoji) 与 [ElevenLabs UI](https://github.com/elevenlabs/ui) 的形式，但没有复制代码或品牌形象，也没有引入 Skia、Three.js。

草稿按学生 UUID＋题本 UUID 本机隔离保存，刷新恢复。提交写后端；相同答卷重试幂等，不同内容不能覆盖。断网、超时保留草稿。开始时间采用服务端返回值、由客户端提交，不能当作防篡改的有效答题时长；未采集逐题停留或离开页面时间。

## 数据、权限及接口

新增 `assessment_rounds`：题本、版本、范围、原题、来源、首次开放时间；`assessment_responses`：原始答案、题本和学生 ID、提交时组别/班级、开始及提交时间。两表加入教师“课堂研究包”，SQL 表从 19 类增加至 21 类，通过 round_id 关联冻结题目、user_id 关联课堂过程。没有回写旧量表、画像快照、图谱或旧账号入门完成标记。

教师管理使用现有管理员认证；学生只能读取自己范围的待填题本、提交自己的答案。教师来源/计分说明不下发学生。关闭、换版、非法选项、未知题号及重复改写由后端拒绝。教师列表最多显示最新 200 份题本。新增表随现有建表流程创建，不重置真实库。

- 教师：`GET/POST /api/admin/assessments`，`PUT /api/admin/assessments/{id}`，`POST /api/admin/assessments/{id}/availability`。
- 学生：`GET /api/assessments/pending`，`POST /api/assessments/{id}/responses`。

## 两组课堂

解构组保留观察、功能卡、单功能流程和函数建构，不恢复系统关系画布或路径规划。普通 AI 组为整文件代码＋贪吃蛇预览，输出可收起，聊天默认收起、可调整大小。普通组助手获得真实运行接口说明，不再误套 L0—L3 限制；教材检索和既有画像算法未改。

普通组从主线程 Pyodide 转为现有 Worker：执行 5 秒超时、50,000 字代码上限、输出截断，支持基础 Python、print、math、random；不能任意导入、访问宿主文件、网络、JS 桥或创建桌面窗口。它不是操作系统级隔离，本轮没有宣称对任意恶意代码完成安全审计。

画布仍为 12×12 贪吃蛇。create_initial_state() 返回蛇身、方向和分数；step_game(state, user_input) 推进一步；辅助函数由学生组织。运行代码接入后再启动游戏，未运行的新编辑不覆盖当前播放版本。执行成功只记录运行完成，不等于功能正确。

这不是嵌入 Pi，也不是任意 Python 可视化运行器。普通组整文件执行没有解构组七函数隐藏测试，实验前仍需对齐运行/评价条件；历史活动任务未自动改写，教师须统一投放课堂贪吃蛇任务。
